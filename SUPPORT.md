# Support

Report bugs and request features in
[GitHub Issues](https://github.com/Azure/substrate-aks/issues).
Search existing issues before opening a new one.

Include the command you ran, the error, your operating system, and the repository
revision. For installation failures, include relevant excerpts from the diagnostic
log. Remove credentials, tokens, kubeconfig contents, and other private data
before posting.

**Do not report security vulnerabilities in public issues.** Follow
[SECURITY.md](SECURITY.md) instead.
